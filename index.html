Abstract

Automated Reward Design (ARD) aims to replace manual reward engineering in reinforcement learning with language-driven reward function synthesis. However, existing approaches based on large language models (LLMs) often rely on semantic associations and iterative environmental feedback to refine task-specific reward hypotheses. This paradigm not only results in inefficient reasoning but also makes LLMs susceptible to semantically plausible yet causally spurious reward components, leading to ineffective optimization. To address these limitations, we propose Causal-ARD, a zero-shot ARD framework that learns transferable causal guidance from offline multi-task interaction data and uses it to constrain reward construction for unseen tasks. Causal-ARD first estimates a coarse reward causal prior from controlled reward-component interventions, and then introduces a joint optimization module that integrates Explicit Mechanism Decoupling with Confidence-Aware Soft Fusion to refine this prior using micro-level trajectories. The resulting prior provides reward-relevant structural guidance while accounting for state-dependent variations in the offline trajectories. During inference, Causal-ARD serializes the refined reward causal prior into explicit constraints that guide an LLM to select supported reward components, prune terms unsupported by the supplied prior, and synthesize executable reward code in a single pass. Our work establishes an interpretable, causal-prior-guided formulation of the ARD problem. Extensive experiments on complex continuous control benchmarks demonstrate that Causal-ARD generates effective rewards without feedback-driven refinement, avoids target-task evolutionary search, achieves performance comparable to the evaluated iterative methods, and generalizes across unseen tasks and diverse robotic embodiments.

Framework

Overview of Causal-ARD. The pipeline consists of three phases: (1) Structural Prior Extraction: Reward-weight interventions produce macro-level configurations and fitness scores, while policy rollouts provide micro-level physical-variable trajectories. A LimiX-based estimator supplies a coarse structural prior. (2) Joint Optimization: Explicit Mechanism Decoupling (EMD) introduces state-dependent coefficient modulation, while Confidence-Aware Soft Fusion calibrates the coarse prior using transition data. The fusion weights represent relative score magnitudes rather than calibrated statistical confidence. (3) Reward Construction: The refined prior, target-task description, and available observations guide component selection and executable reward-code generation in a single pass without feedback-driven refinement.

Conclusions

In this work, we present Causal-ARD, a framework for zero-shot automated reward design. Instead of relying on iterative reward refinement, Causal-ARD learns a reusable reward causal prior from offline multi-task data and uses it to constrain LLM-based reward construction. By combining a reward-relevant structural prior with state-dependent modulation, Causal-ARD selects reward components and synthesizes executable rewards in a single pass. Experiments across unseen simulated tasks and different embodiments show strong task performance without deployment-time evolutionary search; offline evaluation on real-world trajectories supports reward alignment. These results support reusing offline structural guidance to reduce feedback-driven reward search on new tasks.
